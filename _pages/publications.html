Selected Academic Projects (during graduate studies)

Malaria Cell Detection using Faster R-CNN and Curriculum Learning (2023)
Explored Faster R-CNN and curriculum learning using Detectron2 and the M5-Malaria dataset. Converted annotations to COCO format and evaluated detection across different microscopes and magnifications.

View project report (PDF)

Analysis of Traffic-Citation Bias in San Diego (2019)
Analysed San Diego traffic-stop records from the Stanford Open Policing Project. Applied data cleaning and feature selection, comparing neural networks, decision trees, and random forests to examine patterns in ticket issuance.

View project report (PDF)

Liver Disease Prediction using Classification Algorithms (2017)
Compared seven classifiers on the Indian Liver Patient Dataset using Python and scikit-learn. Preprocessed patient biomarker data and evaluated models using accuracy, confusion matrices, and execution time.

View project report (PDF)

Predicting Safety Risks from Street View Photos (2017)
Explored crime-risk classification using street-view imagery and crime records from five U.S. cities. Combined image collection and cleaning, spatial clustering, and support vector machine classification.

View project report (PDF)
