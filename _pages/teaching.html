I have taught and supported undergraduate computer science courses at the Department of Computer Science, College of Computer Engineering and Sciences, Prince Sattam bin Abdulaziz University.

If you are currently enrolled in one of my courses, you can access all course-related materials, announcements, assignments, and learning resources through the official PSAU eLearning System (Blackboard ULTRA) .

Courses Taught

  • Introduction to Artificial Intelligence
    Introduction to the fundamental concepts, methods, and applications of artificial intelligence, including intelligent agents, problem-solving, search techniques, knowledge representation, machine learning, and contemporary AI applications.
  • Large Language Model Development
    Practical introduction to large language models and generative AI, including prompt design, model interaction, AI-assisted application development, and the responsible use of LLM-based systems.
  • Discrete Mathematics
    Mathematical foundations of computer science, including logic, sets, relations, functions, combinatorics, graphs, trees, and proof techniques.
  • Theory of Computation
    Foundations of theoretical computer science, including finite automata, regular languages, context-free grammars, pushdown automata, Turing machines, computability, and computational complexity.
  • Programming I
    Introduction to programming and problem-solving using Java, including variables, control structures, methods, arrays, and basic program design.
  • Programming II
    Object-oriented programming using Java, including classes, objects, inheritance, polymorphism, exception handling, and graphical user interfaces.
  • Data Structures and Algorithms
    Fundamental data structures and algorithmic techniques, including linked lists, stacks, queues, trees, searching, sorting, recursion, and algorithm analysis.
  • Web Applications
    Design and development of database-driven web applications using HTML, CSS, JavaScript, PHP, and MySQL.

Graduation Project Supervision

I supervise undergraduate graduation projects in computer science, including projects developed through research, innovation, and entrepreneurship tracks. My supervision focuses on project planning, requirements analysis, system design, implementation, documentation, presentation, and teamwork.
